# 課堂教學互動白板 - 專為課堂設計的極簡板書工具

> 靈感源自 [Ziteboard](https://app.ziteboard.com/?lang=TW)，專為臺灣中小學及大專院校教師打造的高效數位板書工具。無廣告、無延遲、零依賴、支援本機離線與 GitHub Pages 雲端部署。

---

## 🌟 核心特色功能

### 1. ⚡ 智慧幾何圖形辨識 (Smart Shape Recognition)
- 徒手隨意畫出粗糙的**圓形、橢圓、直線或矩形**，系統自動即時辨識並修正為標準幾何圖形。
- 工具列具備一鍵切換 `[⚡ 智慧幾何]` 開關，方便自由切換寫意筆記或嚴謹幾何繪圖。

### 2. 🔴 教學專屬「流星雷射筆」 (Laser Pointer)
- 在講述投影片、講義或推導公式時，按下 `L` 鍵切換雷射筆。
- 滑鼠或觸控筆拖曳處會呈現發光紅光光暈，並在 1.1 秒內如流星般優雅漸隱消散，既能引導學生視線，又不會留下多餘筆跡。

### 3. 🔦 課堂焦點探照燈 (Spotlight Focus - 快捷鍵 `F`)
- 授課時按下 `F` 或點擊工具列的探照燈，全場畫布會自動優雅壓暗，並以一圈金黃色發光光圈照亮當前滑鼠位置。
- **滾輪縮放**：在探照燈模式下，滑動滑鼠滾輪可自由調整光圈大小（60px ~ 450px）。
- **即時書寫**：探照燈開啟時仍可直接在光圈內書寫板書，再次按下 `F` 或 `Esc` 即可恢復全場明亮。

### 4. 📋 講義題目直接貼上 (Clipboard Paste & Drag)
- 課堂上看到任何網頁教材或題目，直接使用 Windows 內建截圖工具 (`Win + Shift + S`) 截圖。
- 在白板上按下 `Ctrl + V`，立刻將截圖貼上黑板！支援拖曳移動、放大縮小與在上面直接批改筆記。

### 5. 🏫 黑板 / 綠板 / 白板 & 數學網格背景
- **經典白板 (Whiteboard)**：高對比清晰呈現。
- **學校綠板 (Greenboard)**：懷舊校園黑板綠，搭配白/黃/粉筆色彩，親切感十足。
- **護眼黑板 (Blackboard)**：深色墨黑抗疲勞，投影機或大螢幕長時間觀看極為舒適。
- **格線模式**：支援「平面直角坐標網格」、「點陣點紙」、「橫線課堂筆記」與「無格空白」。

### 6. ⏱️ 課堂百寶箱 (Classroom Widgets)
- **課堂倒數計時器**：分組討論、隨堂測驗計時（+1分/+3分/+5分），時間到自動響起溫和清脆提示鐘聲。
- **隨機抽籤器**：可自訂座號（1~35號）或輸入學生名單，大字體隨機滾動抽籤，活躍課堂氣氛。

### 7. 💾 雙層本機持久化記憶 (IndexedDB + LocalStorage)
- **瀏覽器關閉零遺失**：每次打開瀏覽器，自動 100% 重現前一次的板書筆記、所有分頁、最後視野縮放位置與畫筆顏色設定。
- **海量截圖儲存**：結合現代 IndexedDB 大容量技術，貼入多張高解析度講義題目也不怕超出瀏覽器儲存上限。
- **狀態指示燈**：左上角即時顯示「已自動儲存」狀態，授課使用超安心。
- **多頁與匯出**：支援多頁快速切換、一鍵匯出高解析度 PNG 圖片與備份 JSON 檔。

## 🚀 快速啟動方式 (本機執行)

### 方法一：Windows 一鍵開啟 (推薦)
直接雙擊專案目錄下的 **`start-whiteboard.bat`** 即可自動開啟瀏覽器並啟動白板！

### 方法二：終端機執行
```bash
python -m http.server 8090
```
然後開啟瀏覽器前往：`http://localhost:8090`

## 🌐 佈署至 GitHub Pages (免費線上使用)

本專案為純前端原生架構（HTML5 Canvas + ES6 模組 + CSS3），完全無須後端伺服器或打包編譯，可直接部署在 GitHub Pages 上供個人課堂或學生遠端觀看。

### 方式一：使用 Git 指令推送 (推薦)

1. 在 GitHub 上建立一個新的公開或私人儲存庫（Repository），例如命名為 `classroom-whiteboard`。
2. 在本機專案目錄（`d:\Antigravity\whiteboard`）開啟終端機（PowerShell 或 CMD），依序執行以下指令：

```bash
# 1. 關聯至您的 GitHub 儲存庫 (請將 USERNAME 與 REPO 替換為您的帳號與專案名)
git remote add origin https://github.com/USERNAME/REPO.git

# 2. 推送至 GitHub 主分支
git push -u origin main
```

3. 前往 GitHub 儲存庫頁面：
   - 點擊上方 **Settings** ⚙️ ➜ 點擊左側選單 **Pages**
   - 在 **Build and deployment** 下方的 **Source** 選擇：
     - 若使用內建工作流：選擇 **GitHub Actions**（本專案已內建 `.github/workflows/deploy.yml`，會自動秒級完成部署！）
     - 或傳統方式：選擇 **Deploy from a branch**，分支選擇 `main`，目錄選擇 `/ (root)`，按下 **Save**。
4. 約 30 秒至 1 分鐘後，即可在頁面上方看到您的專屬白板網址：
   `https://<你的GitHub帳號>.github.io/<儲存庫名稱>/`

---

### 方式二：使用打包壓縮檔直接網頁上傳

若不想使用命令列，我們已在專案中打包好 `whiteboard-github-deploy.zip`：
1. 在 GitHub 建立新儲存庫後，點擊頁面上的 **uploading an existing file**。
2. 將專案所有檔案拖曳上傳至 GitHub 儲存庫。
3. 按照上方步驟進入 **Settings** ➜ **Pages** 開啟部署即可！

## ⌨️ 快捷鍵速查表

| 功能 | 快捷鍵 | 說明 |
| :--- | :--- | :--- |
| **畫筆** | `P` | 平滑手寫筆觸 |
| **螢光筆** | `H` | 半透明重點標記，不遮擋文字 |
| **橡皮擦** | `E` | 筆畫碰觸即消除 |
| **雷射筆** | `L` | 發光漸隱重點指引 |
| **探照燈** | `F` | 壓暗全場、聚光重點（滾輪可調大小，Esc 關閉） |
| **幾何形狀** | `S` | 快速開啟形狀面板 |
| **文字輸入** | `T` | 點擊任意處輸入課堂標題與註記 |
| **選取移動** | `V` | 選取移動便利貼或圖片 |
| **平移畫布** | `Space + 滑鼠拖曳` 或 `滑鼠中鍵` | 平移無限黑板 |
| **縮放視角** | `滑鼠滾輪` 或 `雙指捏合` | 以滑鼠為中心平滑縮放 |
| **復原** | `Ctrl + Z` | 撤銷上一步動作 |
| **重做** | `Ctrl + Y` | 重做動作 |
| **貼上圖片** | `Ctrl + V` | 直接貼入剪貼簿截圖 |
| **刪除物件** | `Delete` 或 `Backspace` | 刪除當前選取的便利貼或物件 |
| **快捷指南** | `?` | 開啟快捷鍵與指南視窗 |

## 💡 教師上課使用技巧

1. **數學/理化課推薦**：
   - 將背景切換為「方格線」或「點陣」。
   - 開啟幾何圖形面板中的「平面直角坐標系 (X-Y 軸)」，一鍵拉出標準函數坐標軸。
   - 開啟「⚡ 智慧幾何」，徒手隨手畫圓或拋物線參考輔助線，自動規整。
2. **語文/社會課推薦**：
   - 插入課文或簡報截圖 (`Ctrl + V`)。
   - 使用「螢光筆 (H)」劃出關鍵詞，搭配「便利貼」在右側補充字詞意義或補充資料。
3. **分組討論與發表**：
   - 點擊右上角「⏱️」開啟計時器設定 3 分鐘討論。
   - 點擊「🎯」抽籤器，抽出幸運座號學生上台分享解題思路。
